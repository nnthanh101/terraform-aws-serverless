GitHub Actions OIDC Terraform Module
Copyright 2026 Nhat-Thanh Nguyen (nnthanh101@gmail.com)

This module is an original work by Nhat-Thanh Nguyen.

It implements GitHub Actions OIDC federation for AWS IAM using the
token.actions.githubusercontent.com provider with split-trust IAM roles
(plan/readonly role trusted from any ref; apply role trusted from
main branch only).

This product includes no derived upstream code.
